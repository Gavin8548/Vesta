核心亮点

把 Windows 软件，收成一台 Mac 上的游戏库

Vesta 负责导入、预设、美化与监控。兼容引擎继续用你已经信任的 CrossOver 或 Wine。

零配置极速导入

拖入或选择 .exe，Vesta 会解析路径、依赖和分类，几乎不用手工配置容器。

极致性能调优

按应用一键套用图形预设，直接启用 DXVK 或 D3DMetal 转译，让 Apple Silicon 跑得更稳。

引擎自由挂载 (BYOE)

无缝关联本机 CrossOver，或免费开源的 Wine / Porting Kit。引擎你来选，库由 Vesta 管理。

游戏库视觉美化

自动整理海报、高清壁纸和分类。游戏、工具与办公软件各自成组，库面清爽可扫。

极简硬件监控

在启动器里查看 M 系列芯片占用和渲染帧率，判断该用哪一套预设，不必再开监控软件。

100% 隐私安全

纯本地运行。exe、存档和海报都留在这台 Mac 上，Vesta 不上传任何私有文件。

快速上手

三步，从下载到开玩

先装 Vesta，再绑定一个兼容环境。CrossOver 最稳，Wine 与 Porting Kit 可以免费起步。

01

下载并安装 Vesta 客户端

获取 macOS 版并拖入「应用程序」。Vesta 只是启动器，安装本身不替换系统组件。

02

绑定兼容环境

强烈推荐 CrossOver，游戏和常用 Windows 软件都更稳。Vesta 会挂载你本机已经安装的引擎。

获取 CrossOver 专属优惠

也可以免费使用 Wine 或 Porting Kit，Vesta 同样能够识别并调用。

Wine 官网 Porting Kit

03

导入 .exe，一键畅玩

把可执行文件放进游戏库，选好 DXVK 或 D3DMetal，然后直接启动。海报和运行状态会留在库里。

兼容性

为现在的 Mac 准备

Apple Silicon 全系列，加上近几个版本的 macOS。Intel Mac 不在支持范围内。

芯片

Apple Silicon

支持 M1、M2、M3、M4 全系列，包括 Pro、Max 与 Ultra。统一内存建议 16 GB 或更高，以便同时容纳系统和 Windows 容器。

系统

macOS Ventura 及更高

支持 macOS Ventura、Sonoma、Sequoia 以及后续版本。请保持系统更新，以便使用较新的 Metal 图形能力。
